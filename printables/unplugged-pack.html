🌱 CodeKids Unplugged Pack

Screen-free coding games for ages 5–7 · Stage 0 & 1 · CodeKids Academy

What's inside
  1. Arrow cards: the "code" kids use to program a robot (cut out)
  2. Loop & if cards: level-up cards: repeat, and "if wall"
  3. Treasure grid: a 4×4 tabletop maze (or tape one on the floor)
  4. Robot Chef worksheet: write an algorithm a grown-up must follow exactly
  5. Treasure Hunt Code sheet: design a coded hunt for the family
  6. Debug Detective: 4 puzzles: find and fix the bug
How to play (10 minutes to learn)
  1. Put a toy (the robot) on START and a treat on the ⭐ TREASURE.
  2. Your child lays out arrow cards in a line: that's the program.
  3. Run it: move the robot one square per card, exactly as written.
  4. Robot didn't reach the treasure? That's a bug! Find the wrong card and fix it.
  5. Level up: use a repeat card to make the program shorter.
Ask, don't tell: "What did you expect to happen?" · "What actually happened?" · "Which card caused it?" · "What could you try?"

Matches CodeKids milestones m0-0 to m0-5 · CSTA K–12 standards 1A-AP-08, 1A-AP-10, 1A-AP-11, 1A-AP-14. Free to print and share for non-commercial use.

Challenge ladder
  1. Reach the treasure with any program.
  2. Reach it in the fewest cards using repeats.
  3. Add 2 rocks and use an if card to get around them.
  4. Swap roles: your child hides the treasure and writes the program; you are the robot!

🗺️ Treasure grid
