# Parent guide videos: scripts (60–90 seconds each)

**Format:** a phone in portrait, natural light, your face plus your hands or the screen. No editing needed: record in one take, and re-record if you stumble.
**Structure:** Hook (5 s) → What it is (15 s) → How to run it (40 s) → What "done" looks like (15 s) → Encouragement (5 s).
**Privacy:** film hands and screens, not children's faces, unless you have the parents' written OK.

---

## 0 · Welcome to CodeKids (75 s)
**Hook:** "You don't need to know how to code to teach your kid to code. Here's how CodeKids works."
**Show:** Home → Dashboard → Add Student.
**Say:**
> "Add your child with a first name and age. CodeKids picks a starting stage. Tap their card. See **Next up**? That's this week's goal, plus a project that matches it. Open the project: there are steps, a 'done when' check, and a stretch challenge. When your child does it, tick the milestone. 🎉 That's it: one activity a week, about half an hour."

**Close:** "Turn on the Sunday reminder on the Privacy page, and send your check-in each week. Let's go!"

## Stage 0 · Unplugged Logic, ages 5–6 (80 s)
**Hook:** "Your 5-year-old can learn coding with a snack and some paper arrows."
**Show:** the printable arrow cards and the treasure grid.
**Say:**
> "Print the Unplugged Pack from the Curriculum page. Put a toy on START and a treat on the star. Your child lays out arrow cards: that's the program. Now run it: move the toy one square per card. Missed? That's a bug! Ask: 'Which card went wrong?' Fix it, run it again."

**Done when:** "They plan the whole route before moving the toy, and can tell you about one bug they fixed."
**Close:** "Next week, try the Repeat card. Loops are a big idea!"

## Stage 1 · Block Coding, ages 6–7 (75 s)
**Hook:** "Time to move from paper arrows to an app, with no reading or typing needed."
**Show:** ScratchJr: the green flag, motion blocks, a speech bubble.
**Say:**
> "Open ScratchJr. Drag the green flag, then some move blocks, then 'say hello'. Tap the flag. Let your child experiment: what does this block do? Try the Snowflake Loops project on Code.org next: draw a square with 4 blocks, then with one repeat block. Ask: why is the repeat shorter?"

**Done when:** "Their program starts with the green flag and uses three or more blocks in order."

## Stage 2 · Visual Programming, ages 7–9 (85 s)
**Hook:** "This is where kids build real games, with scores, levels and win screens."
**Show:** Scratch, a 'Catch the Apple' game, the variables palette.
**Say:**
> "In Scratch, make a bowl that moves with the arrow keys and apples that fall from the sky. The secret ingredient is a **variable** called score. Every catch adds one. When it works, invite a family member to play-test and write down what they say. Fixing things from feedback is what real developers do."

**Done when:** "The score only goes up when an apple is caught."
**Close:** "Ready to share? Scratch accounts need a parent's email. You set it up."

## Stage 3 · First Real Code, ages 9–11 (85 s)
**Hook:** "Your child is about to type their first real Python program."
**Show:** Trinket.io turtle, then a guessing game in Thonny.
**Say:**
> "Start on Trinket: Python turtle draws shapes with code. Use a for-loop to draw a square, then a hexagon: what number changed? Then build Guess My Number: the computer picks a number and says 'higher' or 'lower'. Have them test it on purpose: guess 1, guess 100, type a word. Errors are clues, not failures: read the red message together."

**Done when:** "The game passes all the test cases in the project brief."

## Stage 4 · Web & Apps, ages 11–13 (80 s)
**Hook:** "Let's put your child's first website on the internet."
**Show:** VS Code or CodePen, an 'All About Me' page, Netlify Drop.
**Say:**
> "Build a one-page site with HTML for the content and CSS for the style. No personal details: no full name, school or address. Then add JavaScript so a button does something. To publish, drag the folder onto Netlify Drop: no account needed. GitHub needs ages 13 and up, or a parent's account."

**Done when:** "It opens on a phone, and every image has alt text."

## Stage 5 · APIs & Automation, ages 13–15 (85 s)
**Hook:** "Now code starts doing real chores and talking to the internet."
**Show:** the Open-Meteo weather API result, then a Python folder-tidy script.
**Say:**
> "An API is a menu other programs order from. Open-Meteo gives weather data with no key needed. Your teen fetches today's temperature and shows it with an emoji. Then the Chore Bot: a Python script that tidies a messy folder. Always on **test copies**, with a dry-run mode that only prints what it would do. That habit will save them one day."

**Done when:** "Dry-run works, and it handles an empty folder."
**Close:** "Any service that needs an account or API key? You own it, and you set the spending limit."

## Stage 6 · AI & Professional, ages 15–18 (90 s)
**Hook:** "Your teen can build with AI responsibly. Here's how."
**Show:** Teachable Machine training on hand signs, then a simple chatbot in a terminal.
**Say:**
> "Start with Teachable Machine: train a model on three hand signs, then test it in different lighting or with someone else's hands. Where does it fail? That's bias in action, and it's the most important AI lesson there is. Next, a Study Buddy chatbot. You create the API account, set a monthly spending limit, and keep the key out of the code. Then they test it with ten tricky questions and improve the instructions."

**Done when:** "The key is never in the code, and the bot stays on-topic in 8 of 10 tests."
**Close:** "The capstone? Solve a real problem for real users, and ship it."

### Recording checklist
- [ ] Phone on a stand, portrait, at eye level
- [ ] Quiet room, window light in front of you
- [ ] Screen recordings: iPhone Control Centre → Screen Recording; Android Quick Settings → Screen recorder
- [ ] Captions (most viewers watch muted): CapCut or Clips can add them automatically
- [ ] Upload unlisted to YouTube; share the links in the pilot group
