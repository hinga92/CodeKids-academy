# Phase 4 pilot kit

| File | Use it for |
|---|---|
| [PILOT_PLAN.md](PILOT_PLAN.md) | The plan: goal, who to recruit, timeline, success metrics, go/no-go |
| [RECRUITMENT.md](RECRUITMENT.md) | Copy-paste invite messages (WhatsApp, email, group welcome) |
| [PARENT_WELCOME.md](PARENT_WELCOME.md) | 1-page guide to send every family (print or export as a PDF) |
| [INTERVIEW_GUIDE.md](INTERVIEW_GUIDE.md) | 15-minute end-of-pilot interview |
| [VIDEO_SCRIPTS.md](VIDEO_SCRIPTS.md) | 60–90 s parent videos, one per stage |
| [pilot_tracker.csv](pilot_tracker.csv) | Log each family's weekly check-in (open in Numbers, Excel or Google Sheets) |

**In the app:**
- **Dashboard → 📋 Weekly check-in** makes an anonymous summary that families send you.
- **Curriculum → Stage 0 → 🖨️ Printable pack** is the unplugged cards and worksheets (`printables/unplugged-pack.html`).
